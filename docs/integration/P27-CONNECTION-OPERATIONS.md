## Rotation, expiry, revocation and disaster recovery

Request a scoped replacement package from Tawsel before expiry or immediately after revocation. Import/verify/confirm it through the same boundary. Include the old signing key and its reviewed overlap deadline for in-flight deliveries, plus the new key last. A key ID cannot be reused with different material. For encryption rotation externally install a new key version on both processes while retaining every old version, select it as `current`, restart both processes in a separately authorized configuration run, then import/confirm the newly encrypted package. Previous immutable imports are not overwritten. Restore native DB plus the entire external key ring and trusted approvals, start in restore mode, validate decryption and original actions/checkpoints, and reconcile before enabling mutation.
